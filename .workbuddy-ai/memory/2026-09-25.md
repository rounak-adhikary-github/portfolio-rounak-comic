## Working note: parallel Edit calls to one file clobber each other

Two `Edit` calls sent to the *same* file in one parallel batch lose one of the two changes
(the second call reads a stale copy and overwrites the first). It reports "Successfully
edited" for both. Two CSS edits were silently lost this way and only surfaced during visual
verification. Send same-file edits one at a time, and grep/verify after each.
