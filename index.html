The Origin Story

I'm a Technology Analyst at Infosys with 7+ years of software development experience, most of it in Core Java and the JVM stack behind enterprise systems: RESTful web services, microservices, JAX-RS, Spring Boot and relational/document databases.

My work sits where engineering meets delivery. I've been in client-facing roles for Boeing, Toyota Motors Europe, HCSC and Cygnet, and I've run an end-to-end PCF-ARO migration in a concierge role — coordinating Product, QA, Platform and DevOps so a migration lands instead of stalling.

Alongside that I write migration playbooks so the next team doesn't rediscover the same failures, and I build data & reporting work (Excel and CSV report generation, ad-services revenue calculation, XML parsing and XSL transformations) for people who need a number they can trust.
